📋 分步操作 · 跟我做

Excel 2010 实操
1

求和公式计算总产量 · 数值型保留1位小数

  • 单击单元格 G3（原煤行的总产量列）， 选择“公式”选项卡→ 自动求和公式：=SUM(C3:F3)，按 Enter 确认。
    此公式将 C3 到 F3（2月~5月）的数值相加，得出原煤的总产量。
  • 填充公式到其余行： 单击选中 G3，将鼠标移至单元格右下角，当光标变为黑色十字填充柄时，双击填充柄，公式自动填充至 G14。
    （或手动拖动填充柄从 G3 到 G14）
  • 设置数值型、保留1位小数： 选中已填充的单元格区域 G3:G14 → 右键 → “设置单元格格式”（或按 Ctrl+1）→ “数字”选项卡 → 分类选择 “数值” → 小数位数设为 1 → 单击“确定”。
  • 验证： 检查 G3 单元格，原煤总产量应显示为 181302.2（保留1位小数）。 其他各行也应正确显示对应总产量。
💡 提示：SUM 函数是 Excel 最常用的求和函数。填充柄双击可自动识别相邻数据区域边界，快速填充公式。设置数值格式不会改变实际数值，仅影响显示方式。
快捷键：选中 G3 后，也可使用 Alt + = 快速插入 SUM 函数，Excel 会自动识别求和范围 C3:F3。

2

按"总产量"降序排序 · 填写序号 1~12

  • 选中数据区域： 单击单元格 A2，按住鼠标左键拖动至 G14，确保选中整个数据表格（含列标题行和12行数据）。
  • 自定义排序： 单击“开始”选项卡（或“数据”选项卡）→ “排序和筛选”组 → 单击 “排序” 按钮（或选择“自定义排序”）→ 弹出排序对话框：
    ▪ 主要关键字：选择 “总产量”（对应 G 列）
    ▪ 排序依据：数值
    ▪ 次序：降序
    ▪ ⚠️ 务必勾选右上角 “数据包含标题” → 单击“确定”。
  • 填写序号： 排序完成后，在 A 列（序号列）从 A3 开始， 依次手动输入 1, 2, 3……12。总产量最高的产品序号为 1，依次递减。
    （可在 A3 输入 1，A4 输入 2，然后选中 A3:A4，拖动填充柄至 A14 快速生成连续序号）
⚠️ 注意：若弹出“排序提醒”对话框，务必选择“扩展选定区域”，确保整行数据一起移动，避免数据错位。排序后原煤（总产量最大）将排在第 3 行（数据区第一行），序号为 1。

3

选择区域 A2:G14 · 行高 20 · 列宽 16

  • 选中指定区域： 鼠标拖动选择单元格区域 A2:G14 （从“序号”列标题到最后一个能源产品的总产量数据，共13行×7列）。
  • 设置行高为 20： 在选中区域的状态下，单击“开始”选项卡 → “单元格”组 → 单击 “格式” 按钮 → 选择 “行高” → 输入 20 → 单击“确定”。
    （此操作将第2行至第14行的行高统一设为20磅）
  • 设置列宽为 16： 保持 A2:G14 选中状态，再次单击“开始”选项卡 → “单元格”组 → 单击 “格式” 按钮 → 选择 “列宽” → 输入 16 → 单击“确定”。
    （此操作将 A 列至 G 列的列宽统一设为16字符宽度）
✅ 行高20磅使数据行更易于阅读；列宽16字符确保各列内容（尤其是“液化天然气(万吨)”等较长指标名称）能够完整显示。设置完成后表格整体更加整齐美观。

4

以 B2:F3 为数据区域 · 创建折线图

  • 选中图表数据源： 鼠标拖动精确选择区域 B2:F3。
    该区域包含：
     • B2 = “指标”（列标题），C2:F2 = 月份（2月~5月，作为分类轴标签）
     • B3 = “原煤(万吨)”（系列名称），C3:F3 = 68659.8, 39579.5, 36279.6, 36783.3（数据值）
  • 插入折线图： 单击“插入”选项卡 → “图表”组 → 单击 “折线图” 图标 → 在下拉样式中选择一种折线图（推荐选择 “带数据标记的折线图”，第2行第1个或第2个样式）。
  • 调整图表（可选）： 图表生成后，可拖动到表格空白区域； 单击图表标题可修改为 “原煤(万吨) 2月~5月产量趋势”； 通过“图表工具-布局”选项卡可添加坐标轴标题、数据标签等。
  • 验证图表： 折线图应显示原煤从 2 月到 5 月的产量变化趋势，横轴为月份（2月、3月、4月、5月），纵轴为产量数值（万吨），图例显示“原煤(万吨)”。
📈 图表解读：B2:F3 区域虽小（2行×5列），但包含了折线图所需的全部要素——系列名称、分类轴标签和数据点。Excel 2010 会自动识别首行作为水平轴标签、首列作为图例项。从图表可直观看出原煤产量在 2 月最高，3~5 月趋于平稳。
最后记得 保存（Ctrl+S），关闭 Excel 并返回考试界面。
